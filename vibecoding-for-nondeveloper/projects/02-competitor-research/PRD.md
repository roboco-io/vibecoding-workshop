# PRD: 경쟁사·시장 리서치 자동 취합

> 비개발자 바이브 코딩 프로젝트 #2 | 기획·PM·디자인·영업 직군 대상 | Claude Project + Artifact 기반

## 1. 배경

비개발자 사전 설문에서 기획/PM/PO가 17%, 디자인 8%, 영업·CS 42% 등 **외부 정보를 모아 의사결정 자료로 가공하는 직군이 다수**다. 응답자들이 직접 제출한 반복 업무 중 "경쟁사 리서치 및 정리", "통계 추이 분석", "신규 서비스 아이데이션"이 공통으로 등장했다.

리서치 작업은 본질적으로 **분산된 정보를 동일한 비교 차원으로 정렬**하는 일이지만, 실무에서는 매번 처음부터 시작한다. 웹페이지를 열어 표를 만들고, PDF에서 발췌하고, 결국 비교 차원이 통일되지 않은 채 보고서를 마감한다. AI 사용자 중 83%가 "결과 품질이 들쑥날쑥"하다고 답한 이유 중 하나는 **리서치 프롬프트가 매번 즉흥적이기 때문**이다.

## 2. 목표

### 핵심 목표

수집한 자료(웹·PDF·메모)를 Claude에 일괄 투입하면 **고정된 비교 차원으로 자동 정렬된 비교표 + 인사이트 리포트**가 나오는 재사용 워크플로우를 만든다.

### 성공 기준

| 기준 | 목표 |
|------|------|
| 경쟁사 5개 비교표 작성 시간 | 평균 4시간 → 1시간 (75% 단축) |
| 동일 차원 적용 일관성 | 100% (프롬프트 고정) |
| 인사이트(차별점·기회) 자동 도출 | 최소 3개/회 |
| 분기 단위 업데이트 가능 | 동일 템플릿으로 재실행 |

### Non-Negotiable

- AI가 인용한 정보는 **출처 명시** (URL·문서명)
- 추정·확신 없는 항목은 "확인 필요" 표시 (사실 단정 금지)

## 3. 사용자

| 항목 | 내용 |
|------|------|
| 주 사용자 | 기획·PM·PO, 마케팅, 영업기획 |
| 보조 사용자 | 디자인 (경쟁 제품 UX 분석), 경영지원 (시장 보고서) |
| 사용 빈도 | 월 1~2회 (분기 보고서·신규 기획 착수 시) |
| 사용 환경 | 회사 노트북 + 브라우저 |

## 4. 핵심 기능

### 4-1. 비교 차원 정의 템플릿

리서치 시작 전 **비교 차원**을 먼저 고정한다:
- **기본 8축**: 타겟 고객 / 가격 모델 / 핵심 기능 / 차별점 / UX·UI / 기술 스택 / 시장 지위 / 최근 동향
- 산업·과제별로 차원을 추가/제거하는 변형 가이드 포함

### 4-2. 자료 일괄 투입

- 웹페이지 텍스트, PDF, 메모, 스크린샷 설명을 한 번에 붙여넣기
- Claude Project에 경쟁사별 폴더 형태로 누적 보관

### 4-3. 비교표 자동 생성 (Artifact)

- 정의한 차원을 행/열로 한 Markdown/Excel 비교표 자동 생성
- Artifact 모드로 시각적으로 검토·수정
- 결측 셀은 **"⚠ 미확보"** 로 명시 (공란 금지)

### 4-4. 결측 정보 식별 + 후속 리서치 가이드

- 비어 있는 셀을 종합하여 "추가로 확인할 항목" 리스트 자동 생성
- 어디서 찾으면 좋은지(공식 사이트/리뷰/뉴스) 출처 후보 제안

### 4-5. 인사이트·기회 자동 도출

- 비교표 기반으로 **차별점·공백 시장·우리 제품 기회**를 자동 추출
- 신규 서비스/기능 아이데이션 프롬프트 패턴 내장

### 4-6. 분기 업데이트 워크플로우

- 직전 비교표를 기준으로 변경 사항만 자동 비교
- "지난 분기 대비 변화 요약" 섹션 자동 생성

## 5. 워크플로우

```
[1회 셋업]
  비교 차원 8축 정의 + 산업별 변형 가이드
       ↓
  Claude Project 생성 + 시스템 프롬프트 고정

[리서치 실행]
  경쟁사 5개 자료 수집 (웹·PDF·메모)
       ↓
  Claude에 일괄 투입
       ↓
  비교표 Artifact 생성 → 검토
       ↓
  결측 항목 후속 리서치 → 재투입
       ↓
  인사이트·기회 도출 프롬프트 실행

[분기 업데이트]
  직전 비교표 + 신규 자료 투입
       ↓
  변경 사항 자동 비교 + 요약
```

## 6. 데이터 및 입력

| 입력 | 형식 | 비고 |
|------|------|------|
| 경쟁사 공식 사이트 | URL/텍스트 발췌 | 출처 보존 |
| 시장 보고서 | PDF | Claude Project Knowledge |
| 사용자 리뷰 | 텍스트 | 익명화 권장 |
| 내부 메모·실사 노트 | 텍스트 | 회사 정보 분리 |
| 직전 비교표 | Markdown/Excel | 업데이트 기준 |

## 8. 제약사항

| 제약 | 대응 |
|------|------|
| 유료 보고서 저작권 | 발췌 인용 범위 준수, 원문 업로드 시 사내 사용 한정 |
| 경쟁사 정보 외부 노출 위험 | 회사 명칭 가명화 옵션 제공 |
| 웹 정보 신뢰도 편차 | 출처 명시 + "확인 필요" 표기 의무화 |

## 9. 검증

```
비교표 초안 생성 → 출처 검증 → 결측 보강 → 인사이트 도출 → 의사결정자 검토
                       ↑
                       └── "AI 단정 표현 금지" 자가 비판 프롬프트
```

**중요 의사결정에 사용되는 셀은 사람이 직접 출처 재확인** 후 표시한다.

## 10. Non-Goals

| 항목 | 이유 |
|------|------|
| 웹 자동 크롤링 | 저작권·로봇 정책 위반 위험, 1단계 범위 외 |
| 실시간 가격 모니터링 | 별도 시스템 필요 |
| 자동 번역 단독 사용 | 뉘앙스 손실 가능, 영문 원문 병기 권장 |

## 11. 확장 가능성

- **신규 서비스 PRD 자동 연계**: 도출된 기회를 프로젝트 #3(문서 초안 생성기)에 투입
- **분기 정기 알림**: Google Calendar 정기 일정 + 업데이트 프롬프트 자동 적용
- **이미지 분석 추가**: 경쟁 제품 스크린샷 → UI 패턴 자동 분류
