# PRD: 동적 예산·실적 시트 자동 편집

> 비개발자 바이브 코딩 프로젝트 #4 | 경영지원·기획 직군 대상 | Claude + Excel/Google Sheets

## 1. 배경

비개발자 설문에서 경영지원(8%)과 기획(17%) 직군이 공통으로 꼽은 반복 업무는 **"경우의 수 반영한 예산 편집 엑셀 파일"** 과 **"통계 추이 분석 데이터 정리"** 다. 응답자가 직접 제출한 사례:

> "인건비·각종 비용 경우의 수를 반영한 예산 엑셀을 매번 수기로 수정하는데, 시나리오마다 수식과 행을 다시 짜야 한다."

> "월·분기 통계 추이를 받아서 인사이트와 시각화 방향을 정리하는 작업이 반복적이지만, 매번 처음부터 시작한다."

데이터 정리·집계가 워크숍 수요 2위(50%)인 만큼 이 직군에만 해당하는 문제가 아니다. 그러나 **수식·통계의 정확성이 의사결정에 직결**되기 때문에 AI에 그대로 맡기기 어렵고, 결과 검증이 반드시 필요하다는 특수성이 있다.

이 프로젝트는 **시나리오 변수 정의 → AI에게 시트 생성 위임 → 사람이 수식 검증 → 실적 비교**라는 안전한 워크플로우를 표준화한다.

## 2. 목표

### 핵심 목표

예산 시나리오 변수와 실적 데이터를 입력하면, **Excel/Google Sheets용 시트 코드와 인사이트 리포트**가 자동 생성되는 워크플로우를 구축한다.

### 성공 기준

| 기준 | 목표 |
|------|------|
| 시나리오 1건당 시트 작성 시간 | 평균 2시간 → 30분 (75% 단축) |
| 수식 검증 통과율 (1차 생성) | 80%+ (검증 필요는 100%) |
| 통계 추이 인사이트 자동 도출 | 최소 3개/회 |
| 분기 결산 자동 비교 가능 | 동일 템플릿 재실행 |

### Non-Negotiable

- **모든 수식은 사람이 검증 후 사용** (AI 단독 결과 신뢰 금지)
- 의사결정에 쓰이는 숫자는 **출처·계산 근거 명시**

## 3. 사용자

| 항목 | 내용 |
|------|------|
| 주 사용자 | 경영지원·재무·기획 담당자 |
| 보조 사용자 | 팀장·매니저 (인사이트 소비자) |
| 사용 빈도 | 월 1~2회 (월간·분기 결산), 수시 (시나리오 검토) |
| 사용 도구 | Excel 또는 Google Sheets + claude.ai |

## 4. 핵심 기능

### 4-1. 시나리오 변수 정의 템플릿

- 인건비 / 외주비 / 마케팅비 / 운영비 / 매출 등 기본 변수 정의
- 시나리오별 변동 범위(낙관·기본·보수) 설정 가이드

### 4-2. Excel/Sheets 시트 생성

- 변수 입력 → Claude가 수식 포함된 시트 구조 자동 생성
- 출력 옵션:
  - **A안**: 셀별 수식 표 (사람이 수동 입력)
  - **B안**: Google Sheets용 수식 코드 (붙여넣기)
  - **C안**: openpyxl/xlsxwriter 기반 Python 코드 (기술 친화 그룹용)

### 4-3. 시나리오 비교 자동화

- 동일 변수로 3개 시나리오 생성 → 비교표 자동 작성
- 각 시나리오의 가정·전제 자동 명시

### 4-4. 실적 vs 예산 차이 분석

- 실적 CSV 업로드 → 예산 대비 차이(%·금액) 자동 계산
- 차이 발생 사유 후보 자동 추출 (변동 항목 자동 식별)

### 4-5. 통계 추이 인사이트 리포트

- 월·분기 추이 CSV 입력 → 트렌드·이상치·시각화 방향 자동 제안
- "이 데이터를 어떻게 시각화할지" 권장 (막대·선·히트맵)

### 4-6. 변동 사유 자동 요약

- 이전 분기 대비 변화량 + 변화율 자동 정리
- 의사결정자용 1페이지 요약 자동 생성

## 5. 워크플로우

```
[1회 셋업]
  기본 예산 항목·변수 정의
       ↓
  Claude Project 생성 (수식 표기법 + 회사 회계 정책 학습)

[시나리오 생성]
  변수값 입력 (낙관·기본·보수)
       ↓
  시트 구조·수식 자동 생성
       ↓
  사람 검증: 수식 정확성·논리·정책 부합
       ↓
  Excel/Sheets에 적용

[실적 비교]
  실적 CSV 업로드
       ↓
  예산 대비 차이 자동 계산
       ↓
  변동 사유 후보 도출
       ↓
  1페이지 요약 자동 생성

[정기 운영]
  분기마다 동일 템플릿 재실행
       ↓
  추이 인사이트 누적
```

## 6. 데이터 및 입력

| 입력 | 형식 | 비고 |
|------|------|------|
| 예산 변수 정의 | 텍스트/표 | 회사 회계 항목 기반 |
| 회사 회계 정책 | Markdown/PDF | Claude Project 학습 |
| 시나리오 가정 | 텍스트 | 변수별 수치 |
| 실적 CSV | CSV | 익명화/원본 모두 가능 (사내) |
| 과거 분기 결산 | CSV | 추이 분석 기준 |

## 8. 제약사항

| 제약 | 대응 |
|------|------|
| 회계 데이터 보안 등급 | 사내 Claude 사용 정책 확인 필수, 필요 시 익명화 |
| 수식 정확성 위험 | 사람 검증 절차 의무화, 수식 결과 샘플 검증 항목 명시 |
| 회계 정책 회사별 차이 | 회사 정책 문서 Project 학습 단계에 포함 |
| Excel 함수 버전 차이 | Excel 365/Google Sheets 등 사용 환경 명시 후 생성 |

## 9. 검증

```
AI 생성 시트
   ↓
수식 정확성 검증 (샘플 셀 수동 계산)
   ↓
정책 부합 검증 (회사 회계 기준)
   ↓
경계값 테스트 (변수 극단값으로 결과 확인)
   ↓
승인 후 의사결정 자료로 사용
```

**검증 체크리스트** (각 시트마다 적용):
- [ ] 합계·소계 수식이 모든 행을 포함하는가
- [ ] 비율 계산의 분모가 정확한가
- [ ] 0 또는 음수 입력 시 #DIV/0 에러가 처리되는가
- [ ] 회사 회계 코드와 항목명이 일치하는가

## 10. Non-Goals

| 항목 | 이유 |
|------|------|
| 회계 시스템 자동 연동 | 보안·권한·감사 추적 이슈로 1단계 외 |
| 결재·승인 자동화 | 책임 소재 명확화 필요 |
| 실시간 환율·시장 데이터 | 별도 API 필요, 1단계 외 |
| 세무 자동 계산 | 전문성·법적 책임 영역, 회계사 검토 필수 |

## 11. 확장 가능성

- **자동 보고서 연결**: 결산 요약을 프로젝트 #3(문서 초안)에 투입
- **시각화 자동화**: Google Sheets 차트 자동 생성 스크립트 (Apps Script)
- **알림 자동화**: 예산 초과 항목 Slack 자동 알림
- **Python 자동화 (기술 친화 그룹)**: openpyxl로 정기 결산 자동 빌드
