CS 문의 자동 분류 에이전트

대상 직군 CS · 영업 · 운영
시간 단축 문의 1건당 15분 → 5분 (66% ↓)
핵심 기능 사양/버그 자동 분류 · 응답 초안 · 인사이트 리포트
현재 문제

같은 패턴 문의에 매번 처음부터 답하고, 사양/버그 구분에 매뉴얼을 다시 뒤지며, 누적 데이터에서 인사이트 뽑을 시간이 없다.

워크플로우
  1. 사양·FAQ·과거 응답을 Claude Project에 한 번 학습
  2. 신규 문의 붙여넣기 → 사양·버그·사용자 실수 자동 분류 + 매뉴얼 근거 인용
  3. 회사 톤앤매너 학습된 응답 초안 생성 → 사람 검토 후 발송
  4. 익명화 누적 CSV → 주간 인사이트 리포트 자동 생성
만들어지는 것
  • Claude Project + 시스템 프롬프트
  • 응답 초안 템플릿 (Slack·이메일)
  • 주간 인사이트 리포트 양식

💡 워크숍에서 만든 Claude Project 패턴을 시각화한 콘셉트입니다

02 / 05

경쟁사·시장 리서치 자동 취합

대상 직군 기획 · PM · 마케팅
시간 단축 5개 경쟁사 비교표 4시간 → 1시간 (75% ↓)
핵심 기능 자료 일괄 투입 · 6차원 비교표 · 인사이트 자동 도출
현재 문제

매번 다른 비교 차원으로 시작해 통일성 없는 표가 나오고, 결측 정보 식별이 사람 직관에 의존한다.

워크플로우
  1. 비교 차원 8축(타겟·가격·기능·차별점·UX·시장지위 등) 한 번 정의
  2. 웹·PDF·메모를 일괄 투입 → Artifact로 비교표 자동 생성
  3. 결측 셀 ⚠ 자동 표기 + 추가 리서치 항목 자동 도출
  4. 차별점·공백 시장·신규 기능 아이데이션 자동 추출
만들어지는 것
  • 비교표 Artifact (Markdown / Excel)
  • 인사이트·기회 도출 리포트
  • 분기 업데이트 재사용 프롬프트

💡 워크숍에서 만든 Claude Project 패턴을 시각화한 콘셉트입니다

03 / 05

문서·보고서 초안 생성기

대상 직군 전 직군 공통
시간 단축 문서 초안 2시간 → 30분 (75% ↓)
핵심 기능 인터뷰 퍼스트 · 구조화된 초안 · 자가 비판 검수
현재 문제

매번 다른 프롬프트·맥락·톤으로 시작해 산출물 품질이 들쑥날쑥. 회사 표준 구조를 매번 AI에게 다시 설명한다.

워크플로우
  1. 회사 표준 샘플 5~10개를 문서 유형별 Project에 학습
  2. 한 줄 아이디어 → AI가 5~10개 질문 던지기 (인터뷰 퍼스트)
  3. 답변 기반 구조화된 초안 자동 생성
  4. 같은 AI에게 자가 비판 → 논리 결함·누락·단정·톤 위반 검출
만들어지는 것
  • 문서 유형별 Claude Project 3~5개 (PRD·제안서·보고서·기획서·회의록)
  • 인터뷰 퍼스트 + 자가 비판 프롬프트 키트
  • 회사 톤앤매너 가이드 (자동 도출본)

💡 워크숍에서 만든 Claude Project 패턴을 시각화한 콘셉트입니다

04 / 05

동적 예산·실적 시트 자동화

대상 직군 경영지원 · 재무
시간 단축 시나리오 시트 2시간 → 30분 (75% ↓)
핵심 기능 시나리오 변수 슬라이더 · 자동 수식 · 실적 차이 분석
현재 문제

시나리오마다 수식과 행을 다시 짜야 하고, 통계 추이 인사이트도 매번 처음부터. 정확성이 의사결정에 직결돼 검증이 필수다.

워크플로우
  1. 회사 회계 항목·정책을 Claude Project에 학습
  2. 시나리오 변수(낙관·기본·보수) 입력 → 수식 포함 시트 자동 생성
  3. 사람이 수식 정확성 검증 → Excel·Google Sheets에 적용
  4. 실적 CSV 업로드 → 차이 분석·변동 사유·1페이지 요약 자동
만들어지는 것
  • 시나리오 비교 가능한 동적 Excel / Google Sheets
  • 실적 차이 분석 리포트 (변동 사유 후보 포함)
  • 분기 결산 재실행 템플릿

💡 워크숍에서 만든 Claude Project 패턴을 시각화한 콘셉트입니다

QA 테스트 케이스·이슈 정리

대상 직군 QA · 운영
시간 단축 QA Plan 3시간 → 1시간 (66% ↓)
핵심 기능 정상/경계/예외/회귀 자동 분류 · 위험 영역 식별
현재 문제

기능마다 정상·경계·예외·회귀를 사람이 처음부터 펼쳐야 하고, AI는 정상 케이스만 제안하기 쉬워 누락 시나리오가 사고로 직결된다.

워크플로우
  1. 회사 QA 표준·위험 영역 체크리스트를 Claude Project에 학습
  2. 기능 명세 입력 → QA Plan + 4종 케이스(정상·경계·예외·회귀) 강제 도출
  3. 위험 영역(동시성·권한·마이그레이션·보안) 자동 식별
  4. raw 이슈 텍스트 → 재현 단계·우선순위 구조화된 카드
만들어지는 것
  • QA Plan + 테스트 케이스 표
  • 위험 영역 체크리스트
  • 회귀 후보 자동 추출 프롬프트
