# 비 개발자를 위한 바이브 코딩 워크숍

용어집
- 코드: 클로드 앱의 코드 모드
- 채팅: 클로드 앱의 채팅 모드
- 코워크: 클로드 앱의 코워크 모드
- 코드 CLI: 클로드 코드 cli


## 환경설정
> 아래 도구들을 Claude Cowork를 사용해서 설치나 설정 하도록 안내. 이미 설치되어 있는지 확인하고 설치되어 있다면 건너 띈다. 클로드에게는 비개발자임을 알려줘서 최대한 손쉽게 진행하고, 클로드가 할 수 있는 작업은 클로드가 하도록 요청한다.
- 클로드 앱 설치
- 코드에서 YOLO 모드 설정
- 코드에서 oh-my-claudecode 설치
- 코드 cli 설치
- 코드 cli 를 YOLO모드로 실행되도록 설정
- git cli 설치
- github cli(gh) 설치 및 로그인
- vscode 설치
- VSCode 클로드 코드 확장기능을 설치하고 YOLO모드 설정

- 코워크에게 워크숍 실습용 빈 폴더를 생성하도록 요청하고, 이를 깃헙에 프라이빗 개인 리포지토리로 등록해 달라고 요청 

## 문제 정의

> 채팅

- 채팅을 사용해서 문제 정의 및 해결방법 탐색하는 방법을 강사가 데모로 진행
  - 수강생도 따라서 각자의 문제점을 가지고 진행한다.
  - 최대한 도전적인 문제를 가지고 해결법을 모색
  - 채팅을 통해 브레인 스토밍 한다.
- 데모 내용을 마크다운으로 다운로드 한다.

> 코드

- 다운로드한 아이디어 문서를 실습용 폴더로 이동시킨다
- 아이디어로부터 프로젝트 PRD를 만들기 위한 심층 인터뷰를 진행한다

> 아티팩트

- PRD를 입력해서 아티팩트로 목업을 생성한다.

> 코드

- 완성된 PRD에 기반해서 목업을 만들어줘. 랄프 루프를 사용해서 끝까지 진행시켜.


> 코드

- 이 프로젝트를 개발자들이 개발할 수 있도록 계획문서를 작성한다
- 계획 문서를 깃헙 이슈에 등록한다.
  - 깃헙 이슈에는 작업 배경, 작업내용, 인수조건, 다른 작업들과의 의존성이 포함되어야 한다

> 코드

- 아키텍처 문서 생성해줘. 다이어그램은 mermaid로 그리고 리드미 업데이트 해줘.

> 코드

- 지금까지 진행한 내용들을 비개발자를 위한 바이브 코딩 튜토리얼로 만들어줘. 비개발자를 위한 깃 매뉴얼도 클로드 코드에서의 프롬프트를 중심으로 만들어줘.
